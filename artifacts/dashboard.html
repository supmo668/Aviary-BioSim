What it shows

Zero parked is the honest result

A run with nothing set aside makes a duller chart, and it is what happened. The worker agent was asked to make one unit hard enough to fail so the demo would have a failure to show, and it refused — an engineered failure is indistinguishable from a real one once it is in the register, which is exactly what the record is supposed to prevent. The repo carries a seeded multi-pass fixture for exercising the improvement view; this page is the real run.

Run it yourself

git clone https://github.com/supmo668/Aviary-BioSim
cd Aviary-BioSim

uv run --with pyyaml dashboard/seed_demo_run.py .        # optional: multi-pass fixture

uv run --with marimo --with pyyaml --with pandas --with altair --with pyarrow \
  marimo run dashboard/v2r_dashboard.py

Source: dashboard/v2r_dashboard.py. It reads .v2r/register.yaml and .v2r/run-record-*.yaml, so it works against any real run rather than a bundled sample.

Why this page shows images instead of the live notebook

marimo's static export preloads its stylesheets from a CDN, and this viewer's content security policy admits scripts from that origin but not stylesheets — so the exported notebook fails to boot here with Unable to preload CSS. We tried it, watched it break, and captured the working notebook instead rather than ship a dead link.

The screenshots above are the notebook running against the real run directory. The command above reproduces it in about thirty seconds.
